MVC Framework Architecture

Learn how requests are routed and handled in this custom-built MVC PHP framework.

1. Routing Flow (Front Controller Pattern)

All requests enter through the public/index.php file. Apache rewrites all requests to the public directory using the .htaccess configuration:

# public/.htaccess
RewriteEngine on
RewriteBase /mvc-php/public
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^(.+)$ index.php?url=$1 [QSA,L]

The Core.php router parses the $_GET['url'] and automatically instantiates the matching controller and executes the requested method.

// Example URL: http://localhost/mvc-php/users/edit/5
// Resolves to:
// Controller: Users
// Method: edit
// Params: [5]

2. Controllers

Controllers must extend the base Controller class. They load models and render views using compilation parameters.

class Pages extends Controller {
    private $pageModel;

    public function __construct() {
        $this->pageModel = $this->model('Page');
    }

    public function index() {
        $data = [
            'title' => 'Dashboard Overview',
            'users_count' => $this->pageModel->countUsers()
        ];
        $this->view('pages/index', $data);
    }
}

3. Template Compilation View Engine

The view compilation engine (implemented inside app/libraries/Controller.php) compiles Blade-like layout instructions into plain PHP syntax on the fly.

Blade Instruction Compiled PHP
{{ $title }} <?php echo htmlspecialchars($title); ?> (Prevent XSS)
@if(condition) ... @endif <?php if(condition): ?> ... <?php endif; ?>
@foreach($items as $item) ... @endforeach <?php foreach($items as $item): ?> ... <?php endforeach; ?>
