Bootstrap / Config

Environment Configuration

The framework uses a simple .env file at the project root to store all environment-specific values (database credentials, app mode, secrets). The env.php bootstrap loader parses it and exposes every key as both $_ENV and getenv().

The .env File

Located at the project root (same level as public/). Each line follows the format KEY=value. Lines starting with # are comments and are ignored.

/.env — Default Keys
# Database credentials
DB_HOST=localhost
DB_USER=root
DB_PASS=
DB_NAME=mvc

# Application environment: development | production
APP_ENV=development

# Optional: backup encryption hash
BACKUP_MASTER_HASH=

Reference table of all built-in keys:

Key Example Value Description
DB_HOST localhost MySQL server hostname or IP address
DB_USER root MySQL database username
DB_PASS secret123 MySQL password (leave blank for no password)
DB_NAME mvc The MySQL database name to connect to
APP_ENV development Environment mode. Use development or production
BACKUP_MASTER_HASH abc123xyz Optional master hash for backup encryption features
Never commit .env to version control. Add it to .gitignore. It contains database passwords and secrets that should never be public.
How env.php Loads the File

app/bootstrap/env.php is included at application startup. It reads and parses the .env file into PHP's superglobals.

1
Resolve path Uses dirname(__DIR__, 2) to climb two levels up from app/bootstrap/ and locate .env at the project root.
2
Read lines Each non-empty, non-comment line is read with file() using FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES.
3
Parse KEY=VALUE Splits each line on the first = with explode('=', $line, 2). Both key and value are trimmed of whitespace.
4
Register globally Each pair is registered via putenv(), $_ENV[], and $_SERVER[] — making it accessible everywhere in PHP.
app/bootstrap/env.php — Source
<?php
$envPath = dirname(__DIR__, 2) . '/.env';

if (!file_exists($envPath)) {
    throw new Exception('.env file not found');
}

$lines = file($envPath, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);

foreach ($lines as $line) {
    if (strpos(trim($line), '#') === 0) continue; // skip comments

    list($key, $value) = array_map('trim', explode('=', $line, 2));

    putenv("$key=$value");   // accessible via getenv('KEY')
    $_ENV[$key] = $value;    // accessible via $_ENV['KEY']
    $_SERVER[$key] = $value; // accessible via $_SERVER['KEY']
}
Accessing Environment Variables

Once loaded, use any of these three methods to read a value:

// Method 1 — getenv() (recommended)
$dbHost = getenv('DB_HOST');   // 'localhost'
$dbName = getenv('DB_NAME');   // 'mvc'
$appEnv = getenv('APP_ENV');   // 'development'

// Method 2 — $_ENV superglobal
$dbUser = $_ENV['DB_USER'];    // 'root'

// Method 3 — $_SERVER superglobal
$dbPass = $_SERVER['DB_PASS']; // ''

// Practical usage in Database.php:
$this->dbh = new PDO(
    'mysql:host=' . getenv('DB_HOST') . ';dbname=' . getenv('DB_NAME'),
    getenv('DB_USER'),
    getenv('DB_PASS')
);
Adding Your Own Variables

You can add any custom key-value pair to .env. No additional code needed — env.php automatically loads all keys on startup.

Adding a Custom Variable
# .env
DB_HOST=localhost
DB_USER=root
DB_PASS=
DB_NAME=mvc
APP_ENV=development

# --- Your custom keys ---
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USER=noreply@myapp.com
MAIL_PASS=supersecret
API_SECRET_KEY=abc123
// Read them anywhere in your app:
$mailHost = getenv('MAIL_HOST');   // 'smtp.gmail.com'
$apiKey   = getenv('API_SECRET_KEY'); // 'abc123'
Deployment — Changing URLROOT

The URLROOT constant controls all generated links (assets, redirects, AJAX calls). It is defined in public/javascript/define.js for the frontend and typically also as a PHP constant. When you deploy to a live domain, you must update it.

Local Development
// public/javascript/define.js
const URLROOT = 'http://localhost/mvc-php';
Production Deployment
// public/javascript/define.js — change to your real domain
const URLROOT = 'https://yourdomain.com';
// If URLROOT is also a PHP constant (e.g. in app/config/config.php):
define('URLROOT', 'https://yourdomain.com');
Pro Tip: To avoid manually editing define.js, move URLROOT into .env as APP_URL=https://yourdomain.com. Then have your PHP bootstrap output it as a JS variable in your HTML layout header: 
<script>
    const URLROOT = '<?php echo getenv("APP_URL"); ?>';
</script>
This way, a single change in .env updates both PHP and JavaScript automatically.
After every change to .env, if you're using PHP-FPM or an opcode cache, restart it. putenv() values are per-process and won't auto-refresh on cached environments.
