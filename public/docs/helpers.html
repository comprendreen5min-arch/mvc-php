Helper Utilities Reference Manual

Complete breakdown of all methods defined inside app/libraries/Helper.php with interactive code demos.

1. Redirection Utilities

Helper::redirect($path)
Sends a Location: HTTP redirect header matching the application URL path. Execution terminates immediately.
Demo Example
// Redirect user back to home route
Helper::redirect('pages/index');
Helper::redirect_to($path, $to)
Chains redirection parameters (e.g. controller name followed by custom parameters).
Demo Example
// Redirects to: URLROOT / users / profile
Helper::redirect_to('users', 'profile');
Helper::redirect_error($path = 'errors/_404')
Redirects users to the application 404 page routing view.
Demo Example
if (!$recordExists) {
    Helper::redirect_error();
}
Helper::redirect_sessions_error($path = 'errors/sessions_search_error')
Redirects user on session validation queries errors.
Demo Example
Helper::redirect_sessions_error();
Helper::redirect_permissions($path = 'errors/error')
Redirects users when they perform operations without matching roles credentials.
Demo Example
if ($_SESSION['user_role'] !== 1) {
    Helper::redirect_permissions();
}

2. Token & Time Utilities

Helper::token($length = 20)
Generates a cryptographically secure pseudo-random hex string value (useful for tokens, CSRF protection, password resets).
Demo Example
$reset_token = Helper::token(40);
// Returns: '8a2b5e9f1c7d6b3a0e4f8d2c6b9a1e3f5c7d8b9a'
Helper::random($min, $max)
Returns a random integer value within the defined constraints using mt_rand.
Demo Example
$pin = Helper::random(1000, 9999);
Helper::random_time()
Wrapper method returning the current server Unix timestamp.
Demo Example
$timestamp = Helper::random_time();

3. HTML Forms Toggles

Helper::is_checked($data)
Evaluates integer value and outputs selected if matching 1. Used inside layout option elements.
Demo Example
<option value="1" <?php echo Helper::is_checked($user->is_active); ?>>Active</option>
Helper::checked($data, $value)
Compares parameters and returns checked if they are equal. Used on checkboxes.
Demo Example
<input type="checkbox" name="roles[]" value="3" <?php echo Helper::checked($user->role_id, 3); ?>>
Helper::is_selected($data, $value)
Compares parameters and returns selected if they are equal. Used inside selection lists.
Demo Example
<select name="country">
    <option value="MA" <?php echo Helper::is_selected($user->country, 'MA'); ?>>Morocco</option>
</select>
Helper::return_date($datetime, $dateformat = 'Y-m-d')
Formats custom database DateTime inputs into clean visual layout strings. Returns null if input is empty.
Demo Example
echo Helper::return_date($user->created_at, 'd M Y');
// Outputs: "30 Jun 2026"

4. Upload Files & Empty Handlers

Helper::file_handle($file_name)
Processes single uploads. Replaces non-alphanumeric chars from file prefix with hyphens and resolves file structure mapping array.
Demo Example
$file = $this->help->file_handle('avatar');
if ($file) {
    move_uploaded_file($file['file_temp'], 'uploads/' . $file['file_name']);
}
Helper::files_handle($file_name)
Processes multiple arrays of file uploads, yielding an array list containing name mappings and temporary locations.
Demo Example
$files = $this->help->files_handle('gallery_images');
foreach ($files as $file) {
    move_uploaded_file($file['file_temp'], 'uploads/gallery/' . $file['file_name']);
}
Helper::file_handle_empty($destination_folder, $new_file_name, $default_image = 'default_image.jpg')
Checks upload destination path, and copies a fallback placeholder image into that folder if empty.
Demo Example
// Copies standard default avatar to user directory
Helper::file_handle_empty('avatars/', 'user_5_avatar.jpg', 'placeholder.jpg');

5. Flash Alerts System

Helper::flash($name, $message = '', $class = '')
Saves key-value message blocks inside session cookies. Supports custom CSS styles (e.g. alert-success). Also accepts predefined alert methods dynamically.
Demo Example
// Set custom alert message
Helper::flash('profile_msg', 'Settings updated!', 'alert-success');

// Use predefined warning alert
Helper::flash('warning');
Helper::flash_message($name = 'message')
Echos the visual alert block to layout and purges it from session/cookie variables.
Demo Example
<div class="alerts-container">
    <?php Helper::flash_message('profile_msg'); ?>
</div>
Predefined alert methods: success() / danger() / warning() / info()
Outputs predefined message structures for quick status processing checks.
Demo Example
// Equivalent to Helper::flash('warning')
Helper::flash('warning');

6. Layout & Route Elements

Helper::breadcrumb_url()
Formats active navigation levels into HTML breadcrumbs. Parses controller, actions routing params automatically.
Demo Example
<ul class="breadcrumb">
    <?php Helper::breadcrumb_url(); ?>
</ul>
Helper::renderMenuItem($title, $icon, $url, $subItems, $allowedRoles)
Prints HTML template codes for sidebar navigation, reviewing active session role authorization rules.
Demo Example
// Render menu links ONLY for role 1 (Admin)
echo Helper::renderMenuItem('Settings', 'fa fa-cog', URLROOT.'/settings', [], [1]);
Helper::status($status_value)
Returns HTML icon blocks matching active integer state (value 1 shows check circle, value 0 shows pause circle).
Demo Example
echo Helper::status($user->user_status);
Helper::slugify($text)
Replaces special formatting characters and symbols from custom texts with hyphens to make clean URL strings.
Demo Example
echo Helper::slugify('Hot Air Balloon CRM #5!');
// Outputs: "hot-air-balloon-crm-5"

7. Cryptography & Formatting

Helper::encrypt($data) / Helper::decrypt($data)
Performs AES-256-CBC encryption using secret keys defined inside application helpers.
Demo Example
$encrypted = Helper::encrypt('my_smtp_password');
$decrypted = Helper::decrypt($encrypted);
Helper::number_to_text($number, $lang = 'fr_FR')
Converts decimal numeric parameters into spelled out letters utilizing spellout algorithms.
Demo Example
echo Helper::number_to_text(2500, 'en_US');
// Outputs: "two thousand five hundred"
Helper::truncate(string $text, int $limit = 100, string $end = '...')
Trims down strings length to specified character constraints, appending custom trail indicators.
Demo Example
echo Helper::truncate('This is a very long string description sample', 15);
// Outputs: "This is a very ..."

8. Field Inputs Sanitization & Filters

Helper::text(string $field, $source = INPUT_POST)
Filters input fields, converting tags to prevent cross site scripting injection issues.
Demo Example
$first_name = Helper::text('first_name');
Helper::email(string $field, $source = INPUT_POST)
Validates email address formatting and clears illegal parameters.
Demo Example
$email = Helper::email('email');
Helper::int(string $field, $source = INPUT_POST)
Returns value as valid integer, returning null if empty or invalid.
Demo Example
$age = Helper::int('age');
Helper::float(string $field, $source = INPUT_POST)
Validates and filters decimal inputs parameters.
Demo Example
$price = Helper::float('price');
Helper::url(string $field, $source = INPUT_POST)
Validates and sanitizes standard URL string formats.
Demo Example
$website = Helper::url('website');
Helper::bool(string $field, $source = INPUT_POST)
Evaluates parameters and checks standard boolean triggers.
Demo Example
$agree = Helper::bool('agree_terms');
Helper::raw(string $field, $source = INPUT_POST)
Retrieves the unprocessed value of a field without filtering. Use carefully.
Demo Example
$raw_payload = Helper::raw('webhook_data');
Helper::html_special_chars(string $field, $source = INPUT_POST)
Sanitizes rich parameters, converting characters like quotes or brackets to safe HTML entities.
Demo Example
$description = Helper::html_special_chars('product_description');
Helper::html_special_chars_decode(string $field)
Translates compiled HTML special entities back to raw HTML codes. Use when rendering layouts.
Demo Example
echo Helper::html_special_chars_decode($product->description);
