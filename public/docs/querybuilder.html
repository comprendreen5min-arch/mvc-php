QueryBuilder Class Reference

Learn how to use the fluent QueryBuilder wrapper class to construct secure SQL statements dynamically.

1. Chained Data Selection API

$this->table($name)

Initializes the QueryBuilder instance for a targeted database table. This is always the starting point of the chain.

$query = $this->table('users');
select($columns = '*')

Sets custom target columns for the query retrieval instead of pulling all columns.

$users = $this->table('users')
    ->select('id, first_name, email')
    ->get();
get()

Executes the constructed query layout against the database and yields a result set array of objects.

$activeManagers = $this->table('users')
    ->where('user_role', 2)
    ->get();
first()

Retrieves the first matching record object or returns null if no rows matches requirements.

$adminUser = $this->table('users')
    ->where('user_role', 1)
    ->first();
count()

Constructs and executes an SQL COUNT(*) query based on defined conditions, returning the integer total.

$totalPartners = $this->table('users')
    ->where('user_role', 3)
    ->count();

2. SQL Filtering Constraints

where($column, $value, $operator = '=')

Adds standard column restrictions. Supports custom operators (e.g. <, >, LIKE).

$recentUsers = $this->table('users')
    ->where('id', 10, '>')
    ->get();
whereIn($column, array $values)

Restricts queries to records where values match a collection array.

$users = $this->table('users')
    ->whereIn('user_role', [1, 2])
    ->get();
whereLike($column, $value)

Wrapper method triggering a standard SQL LIKE comparison check.

$users = $this->table('users')
    ->whereLike('email', '%@domain.com')
    ->get();
whereNull($column) / whereNotNull($column)

Includes SQL IS NULL or IS NOT NULL queries parameters.

// Fetch records without phone numbers
$users = $this->table('users')->whereNull('phone')->get();

3. Sorting & Pagination Limits

orderBy($column, $direction = 'ASC')

Sets standard sorting parameters to organize query data.

$users = $this->table('users')
    ->orderBy('first_name', 'ASC')
    ->get();
limit($limit, $offset = 0)

Limits query return size and sets database pagination offsets.

$pageThreeUsers = $this->table('users')
    ->limit(10, 20)
    ->get();

4. Database Data Mutations (CRUD)

insert(array $data)

Inserts a raw data record mapping key parameters to column values. Executed immediately.

$this->table('users')->insert([
    'first_name' => 'Steve',
    'email' => 'steve@apple.com'
]);
update(array $data) / save()
Safety Constraint: The QueryBuilder enforces specifying a where() query prior to saving updates. Calling save() without conditions triggers an Exception.

Prepares target changes and executes the statement upon calling save().

$this->table('users')
    ->where('id', 5)
    ->update(['first_name' => 'Steven'])
    ->save();
delete()

Performs database delete statement execution. Requires an active where() clause beforehand.

$this->table('users')
    ->where('id', 5)
    ->delete();
softDelete()

Updates the target record, setting `soft_delete = 0` to hide it from standard finders.

$this->table('users')
    ->where('id', 5)
    ->softDelete();
