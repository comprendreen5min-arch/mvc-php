Model Base Class Reference

Complete documentation of all database query wrapper functions provided by the base Model class.

1. QueryBuilder Initialization

$this->table($tableName)

Retrieves a fluent, chainable QueryBuilder instance pre-configured for the specified database table.

$activeUsers = $this->table('users')
    ->where('user_status', 1)
    ->get();

2. Basic Finders & Retrieval

$this->findById($table, $id)

Finds a single record object matching the unique primary ID.

$user = $this->findById('users', 12);
echo $user->email;
$this->findOne($table, $column, $value)

Finds a single record object matching a custom column check.

$user = $this->findOne('users', 'email', 'john@gmail.com');
$this->all($table)

Returns all active records (filtered by soft_delete = 1) sorted descending by primary ID.

$products = $this->all('products');
$this->latest($table)

Returns the newest created active record filtered by soft_delete = 1.

$lastProduct = $this->latest('products');
$this->whereAll($table, $column, $value, $orderBy = 'id', $direction = 'DESC')

Finds multiple active records matching a specific column criteria, sorted by your criteria.

$userProducts = $this->whereAll('products', 'admin_id', 5, 'product_name', 'ASC');

3. Database Constraints Validation

$this->exists($table, $column, $value)

Returns boolean indicating whether a record matching the column exists in the database.

if ($this->exists('users', 'email', 'test@domain.com')) {
    echo "Email already taken!";
}
$this->existsWhere($table, array $conditions)

Dynamic check verifying whether a record matches multiple column specifications simultaneously.

$isPilotFree = $this->existsWhere('flights', [
    'pilot_id' => 5,
    'status' => 'Scheduled'
]);

4. Active User Session Shortcuts

$this->userField($field)

Retrieves database column details for the currently logged-in user session (based on $_SESSION['user_id']).

$currentUserRole = $this->userField('user_role');

5. Record Deletion Helpers

$this->softDelete($table, $id)

Sets soft_delete = 0 on the target primary ID.

$this->softDelete('products', 15);
$this->hardDelete($table, $id)

Performs a raw SQL DELETE statement removing the row from the database.

$this->hardDelete('products', 15);
$this->delete($table, $id)

Checks if the ID exists in the database. If it exists, triggers a safe softDelete() returning true.

if ($this->delete('products', 15)) {
    echo "Product deleted successfully!";
}

6. Record Counters

$this->count($table)

Returns the total count of active records (where soft_delete = 1).

$totalActiveUsers = $this->count('users');
$this->countWhere($table, $column, $value)

Returns the total count of active records matching a custom column condition.

$totalManagers = $this->countWhere('users', 'user_role', 2);

7. Dynamic CRUD Selectors

$this->insert($table, array $data)

Prepares an insert query, dynamically binds parameters, and inserts into the database.

$this->insert('products', [
    'product_name' => 'Hot Air Balloon Ride',
    'product_price_adults' => 1500.00
]);
$this->update($table, array $data, array $where)

Updates records matching the specified target criteria parameters.

$this->update('products', 
    ['product_price_adults' => 1700.00], 
    ['id' => 12]
);
$this->select($table, array $where, $columns = '*', $multiple = false)

Dynamically runs custom SELECT queries. Fetches a single object or a result set array based on the $multiple flag.

// Fetch active products list
$products = $this->select('products', ['soft_delete' => 1], 'id, product_name', true);
$this->selectCustom($table, $whereClause, array $bindings, $columns = '*', $multiple = false)

Generic SELECT query template matching raw SQL WHERE parameters.

$user = $this->selectCustom('users', 
    'user_role = :role AND user_status = :status', 
    ['role' => 1, 'status' => 1]
);
$this->selectOrdered($table, array $where, $orderBy = 'id', $direction = 'DESC', $columns = '*')

Selects multiple objects matching query constraints sorted dynamically.

$users = $this->selectOrdered('users', ['user_role' => 3], 'first_name', 'ASC');
$this->selectLimit($table, array $where, $limit = 10, $offset = 0, $columns = '*')

Selects multiple records with pagination offset limitations.

$products = $this->selectLimit('products', ['soft_delete' => 1], 10, 20);

8. Status Toggle Operations

$this->toggleStatus($table, $id, $column = 'user_status')

Toggles the value of a target status column (e.g. user_status) between 0 and 1.

// Toggles active status of user ID 8
$this->toggleStatus('users', 8);
