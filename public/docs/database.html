Database Wrapper (PDO Class)

Learn how to use raw SQL statement operations safely using the custom Database wrapper class.

1. Initializing inside a Model

The base Model automatically instantiates the Database class wrapper in the constructor, which is then accessible via $this->db.

class UserModel extends Model {
    public function getUser($id) {
        $this->db->query("SELECT * FROM users WHERE id = :id");
        $this->db->bind(':id', $id);
        return $this->db->single();
    }
}

2. Preparing & Binding Parameters

Always bind your parameters using the bind() function. This prevents SQL injection attacks by ensuring the values are properly parameterized.

$this->db->query("SELECT * FROM users WHERE email = :email AND status = :status");
$this->db->bind(':email', $email, PDO::PARAM_STR);
$this->db->bind(':status', 1, PDO::PARAM_INT);

3. Fetching Results

There are multiple ways to retrieve your results based on the number of expected columns or rows:

A. Multiple Rows (resultSet)

Returns an array of row objects.

$results = $this->db->resultSet();
foreach($results as $row) {
    echo $row->first_name;
}
B. Single Row (single)

Returns a single row object.

$user = $this->db->single();
echo $user->email;
C. Row Count (rowCount)

Returns the number of affected rows of the last query.

$count = $this->db->rowCount();

4. Query Transactions

You can use standard transactions to ensure multiple queries complete successfully together, rolling back changes if any query encounters an error:

try {
    $this->db->beginTransaction();

    $this->db->query("INSERT INTO bookings (customer_id) VALUES (:id)");
    $this->db->bind(':id', $customerId);
    $this->db->execute();

    $this->db->query("UPDATE accounts SET balance = balance - :amount WHERE id = :id");
    $this->db->bind(':amount', 500);
    $this->db->bind(':id', $customerId);
    $this->db->execute();

    $this->db->commit();
} catch (PDOException $e) {
    $this->db->rollBack();
    // Handle error...
}
