SessionHelper — Authentication & Access Control

The SessionHelper class (located at app/helpers/SessionHelper.php) manages user sessions, role checks, and access control enforcement. Use it in every controller constructor to protect pages from unauthorized access.

Critical Rule: Hiding a sidebar menu item does NOT prevent access. You must call $this->session->requireRoles() in your controller constructor to enforce permissions at the backend level.

1. Setting Up in a Controller

Standard Controller Setup Pattern
Every protected controller follows the same pattern: instantiate SessionHelper, call a role guard, then store user info for later use.
Complete Example
class PartnersProducts extends Controller
{
    private $mod;
    private $help;
    private $session;
    private $adminId;
    private $adminName;

    public function __construct()
    {
        // Load model and helpers
        $this->mod = $this->model('PartnersProduct');
        $this->help = new Helper();

        // Initialize SessionHelper
        $this->session = new SessionHelper();

        // ✅ ENFORCE ACCESS CONTROL — Only Admins (role 1) allowed
        $this->session->requireRoles([1], 'errors/error');

        // Store user info for audit trails
        $this->adminId   = $this->session->getUserId();
        $this->adminName = $this->session->getUserName();
    }
}
The requireRoles() call must be in the constructor. It runs before any method, so every action in this controller is automatically protected.

2. Session Data Getters

isLoggedIn()
Returns true if a user session exists (i.e. $_SESSION['user_id'] is set and non-empty).
$session = new SessionHelper();

if ($session->isLoggedIn()) {
    echo "User is authenticated";
} else {
    echo "Not logged in";
}
getUserId()
Returns the current user's id from the session, or null if not logged in.
$userId = $session->getUserId();   // e.g. 42
getUserRole()
Returns the current user's role ID (integer) from the session, or null.
$roleId = $session->getUserRole();  // e.g. 1 (Admin), 3 (Partner)
getUserEmail()
Returns the current user's email address from the session, or null.
$email = $session->getUserEmail();  // e.g. "admin@company.com"
getUserName()
Returns the user's full name by concatenating $_SESSION['first_name'] and $_SESSION['last_name'].
$fullName = $session->getUserName();  // e.g. "John Doe"
getRoleName($roleId = null)
Converts a numeric role ID to its human-readable name. Defaults to the current user's role if no parameter is passed.
// Current user's role name
echo $session->getRoleName();       // "Admin"

// Specific role ID
echo $session->getRoleName(3);      // "Partner"
echo $session->getRoleName(6);      // "Pilot"
echo $session->getRoleName(99);     // "Unknown"

}

4. Access Control Guards (Enforcement)

requireLogin($redirect = 'logins/index')
Checks if the user is logged in. If not, sets a flash message and redirects to the login page. Execution stops immediately via Helper::redirect().
Example — Protect a page for any authenticated user
class Profile extends Controller
{
    public function __construct()
    {
        $this->session = new SessionHelper();
        
        // Any logged-in user can access, regardless of role
        $this->session->requireLogin();
    }
}
Custom redirect target
// Redirect to a custom page instead of the login page
$this->session->requireLogin('pages/maintenance');
requireAdmin($redirect = 'errors/error')
Shortcut that redirects non-admin users (role ≠ 1) to an error page with an "Access denied" flash message.
Example — Admin-only controller
class Settings extends Controller
{
    public function __construct()
    {
        $this->session = new SessionHelper();
        
        // Only role 1 (Admin) can access
        $this->session->requireAdmin();
    }
}
requirePartner($redirect = 'errors/error')
Shortcut that redirects non-partner users (role ≠ 3) to an error page. 
class PartnerBookings extends Controller
{
    public function __construct()
    {
        $this->session = new SessionHelper();
        
        // Only role 3 (Partner) can access
        $this->session->requirePartner();
    }
}
⭐ requireRoles(array $allowedRoles, $redirect)
The most flexible and recommended guard. Checks if the user is logged in and if their role is in the $allowedRoles array. If not, redirects with an "Access denied" flash message. This is the preferred method for all new controllers.
Parameters
ParameterTypeDefaultDescription
$allowedRoles array — Array of role IDs that are allowed access. e.g. [1, 2]
$redirect string 'errors/error' URL path to redirect to if access is denied.
Example 1 — Admin only
$this->session->requireRoles([1], 'errors/error');
Example 2 — Admin + Manager
$this->session->requireRoles([1, 2], 'errors/error');
Example 3 — Partner + Transporter
$this->session->requireRoles([3, 4], 'errors/error');
Example 4 — All roles except Greeter
$this->session->requireRoles([1, 2, 3, 4, 5, 6, 7], 'errors/error');
Best Practice: Always use requireRoles() instead of requireAdmin() or requirePartner(). It's more flexible and makes it easy to add new roles later without touching the SessionHelper class.

5. Role-Based Redirect

redirectByRole()
Redirects the user to their role-specific dashboard after login. Typically called from the login controller after successful authentication.

Example — After login success
class Logins extends Controller
{
    public function login()
    {
        // ... validate credentials, start session ...

        if ($loginSuccess) {
            $_SESSION['user_id']   = $user->id;
            $_SESSION['user_role'] = $user->role;
            $_SESSION['first_name'] = $user->first_name;
            $_SESSION['last_name']  = $user->last_name;
            $_SESSION['email']      = $user->email;

            // Redirect to the correct dashboard
            $session = new SessionHelper();
            $session->redirectByRole();
        }
    }
}

6. Destroy Session (Logout)

destroy()
Clears all session data and destroys the session. Call this in your logout controller method. 
class Logins extends Controller
{
    public function logout()
    {
        $session = new SessionHelper();
        $session->destroy();

        Helper::redirect('logins/index');
    }
}

7. Complete Real-World Controller Example

Full Controller with SessionHelper
This is a complete, production-ready controller showing all SessionHelper patterns in context — access control, user data for audit trails, and permission-guarded methods. 
<?php

class PartnersProducts extends Controller
{
    private $mod;
    private $help;
    private $session;
    private $adminId;
    private $adminName;

    public function __construct()
    {
        // Load model
        $this->mod = $this->model('PartnersProduct');
        $this->help = new Helper();

        // ① Initialize SessionHelper
        $this->session = new SessionHelper();

        // ② Enforce access — Only Admins (role 1) can access
        $this->session->requireRoles([1], 'errors/error');

        // ③ Store user info for audit logging
        $this->adminId   = $this->session->getUserId();
        $this->adminName = $this->session->getUserName();
    }

    public function index()
    {
        $appSettings = $this->mod->table('app_settings')->get();
        $appCurrency = !empty($appSettings)
            ? $appSettings[0]->app_currency
            : 'MAD';

        $data = [
            'URLROOT'      => URLROOT,
            'PRODUCTS'     => PRODUCTS,
            'app_currency' => $appCurrency
        ];

        $this->view('partnersproducts/index', $data);
    }

    public function store()
    {
        if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
            Helper::flash('partner_product_message', 'Invalid request', 'alert-danger');
            Helper::redirect('errors/error');
        }

        $data = [
            'partner_id'   => $this->help->int('partner_id'),
            'product_name' => $this->help->text('product_name'),
            // ... other fields
            'admin_id'     => $this->adminId,      // ← audit trail
            'admin_name'   => $this->adminName      // ← audit trail
        ];

        $result = $this->mod->table('partners_products')->insert($data);

        if ($result) {
            Helper::flash('partner_product_message', 'Added!', 'alert-success');
        } else {
            Helper::flash('partner_product_message', 'Failed!', 'alert-danger');
        }
        Helper::redirect('partnersproducts/index');
    }
}

8. Common Access Control Patterns

Pattern A: Single Role
Only one role can access the entire controller.
// Admin-only controller
$this->session->requireRoles([1], 'errors/error');

// Partner-only controller  
$this->session->requireRoles([3], 'errors/error');

// Transporter-only controller
$this->session->requireRoles([4], 'errors/error');
Pattern B: Multiple Roles
Several roles share the same controller but may see different data.
// Admin + Manager can both manage bookings
$this->session->requireRoles([1, 2], 'errors/error');

// Admin + Partner + Transporter can view reports
$this->session->requireRoles([1, 3, 4], 'errors/error');
Pattern C: Per-Method Access Control
Allow broad access in the constructor, then restrict specific methods. Useful when some actions (like viewing) are open to many roles but editing is restricted. 
class Reports extends Controller
{
    public function __construct()
    {
        $this->session = new SessionHelper();
        // Any authenticated user can access the controller
        $this->session->requireLogin();
    }

    public function index()
    {
        // Everyone can view reports
        $this->view('reports/index');
    }

    public function export()
    {
        // Only Admin and Manager can export
        $this->session->requireRoles([1, 2], 'errors/error');
        
        // ... export logic
    }

    public function delete($id)
    {
        // Only Admin can delete
        $this->session->requireRoles([1], 'errors/error');

        // ... delete logic
    }
}
Pattern D: Conditional View Content
Pass role info to the view so the template can show/hide UI elements. 
// In the controller
$data = [
    'isAdmin'   => $this->session->isAdmin(),
    'isManager' => $this->session->isManager(),
    'roleName'  => $this->session->getRoleName(),
    'userName'  => $this->session->getUserName()
];
$this->view('dashboard/index', $data);

// In the view template
<?php if ($data['isAdmin']) : ?>
    <button class="btn btn-danger">Delete All</button>
<?php endif; ?>

<?php if ($data['isAdmin'] || $data['isManager']) : ?>
    <a href="reports/export">Export CSV</a>
<?php endif; ?>

9. Security Checklist

Use this checklist every time you create a new controller:
✓CheckHow
☐ Constructor has new SessionHelper() Instantiate in __construct()
☐ Constructor calls requireRoles() or requireLogin() Choose the right guard for your access level
☐ Sidebar menu item uses same role IDs Match $allowedRoles in aside.php
☐ POST-only methods check $_SERVER['REQUEST_METHOD'] Prevent GET requests to data-modifying actions
☐ Audit fields include admin_id / admin_name Use getUserId() and getUserName()
