Core Library

Controller Base Class

The Controller class is the base that all your application controllers extend. It provides model() and view() methods, plus a built-in Blade-like template engine for clean PHP views.

model()
$this->model(string $model) : object

Loads a Model class file from app/models/, instantiates it, and returns the object. Call this in your controller's constructor to make the model available throughout all methods.

// In your controller __construct():
$this->userModel = $this->model('User');
// Loads: app/models/User.php
// Returns: new User()

// Then use it in any method:
public function index() {
    $users = $this->userModel->all('users');
}
Model filename = class name. Passing 'User' loads app/models/User.php and instantiates class User. The names must match exactly (case-sensitive).
view()
$this->view(string $view, array $data = []) : void

Loads a view file from app/views/, compiles its template directives, extracts the $data array into PHP variables, and renders the output. Supports slash-separated subdirectory paths.

// Load: app/views/users/index.php
// Pass $users variable into the view
$this->view('users/index', [
    'users'      => $users,
    'pageTitle'  => 'All Users',
    'totalCount' => count($users)
]);

// In the view file, access them directly:
// {{ $pageTitle }}      → outputs "All Users"
// {{ $totalCount }}     → outputs the count
The view uses a temporary file mechanism — the compiled PHP is written to sys_get_temp_dir() and executed, then deleted automatically. This is transparent to you.
Built-in Template Engine

The compileView() private method translates Blade-like syntax into standard PHP before rendering. You can use these directives inside any .php view file.

Output Directive — {{ }}
{{ $variable }}

Outputs a variable safely with htmlspecialchars() (XSS-protected). Uses null-coalesce so missing variables won't throw errors.

// In the view file:
<h1>{{ $pageTitle }}</h1>
<p>Welcome, {{ $user->first_name }}</p>
<span>{{ $user->role ?? 'Guest' }}</span>

// Compiles to:
// <?php echo htmlspecialchars(($pageTitle) ?? "", ENT_QUOTES, 'UTF-8'); ?>
Control Structure Directives
@if ($condition)
→ <?php if($condition): ?>
@elseif ($condition)
→ <?php elseif($condition): ?>
@else
→ <?php else: ?>
@endif
→ <?php endif; ?>
@foreach ($arr as $item)
→ <?php foreach($arr as $item): ?>
@endforeach
→ <?php endforeach; ?>
@for ($i = 0; $i < 5; $i++)
→ <?php for($i=0;$i<5;$i++): ?>
@endfor
→ <?php endfor; ?>
@while ($condition)
→ <?php while($condition): ?>
@endwhile
→ <?php endwhile; ?>
View Template Example

A real-world example combining all directives in a view file:

<!-- app/views/users/index.php -->
<h1>{{ $pageTitle }}</h1>
<p>Total: {{ $totalCount }} users</p>

@if ($totalCount > 0)
    <table>
        <tbody>
        @foreach ($users as $user)
            <tr>
                <td>{{ $user->first_name }}</td>
                <td>{{ $user->email }}</td>
                @if ($user->user_status == 1)
                    <td><span class="badge bg-success">Active</span></td>
                @else
                    <td><span class="badge bg-danger">Inactive</span></td>
                @endif
            </tr>
        @endforeach
        </tbody>
    </table>
@else
    <p>No users found.</p>
@endif
Full Controller Example

A complete controller showing constructor model loading, multiple actions, and view rendering with data:

// app/controllers/Users.php
class Users extends Controller
{
    private $userModel;

    public function __construct()
    {
        // Load the User model once — reused in every method
        $this->userModel = $this->model('User');
    }

    // /users  or  /users/index
    public function index()
    {
        $data = [
            'pageTitle' => 'Manage Users',
            'users'     => $this->userModel->all('users'),
        ];
        $this->view('users/index', $data);
    }

    // /users/edit/5
    public function edit($id)
    {
        $data = [
            'pageTitle' => 'Edit User',
            'user'      => $this->userModel->findById('users', $id),
        ];
        $this->view('users/edit', $data);
    }

    // /users/delete/5
    public function delete($id)
    {
        $this->userModel->delete('users', $id);
        header('Location: ' . URLROOT . '/users');
        exit;
    }
}
Best Practice: Always load models in __construct() — not inside individual methods. This avoids re-instantiation and keeps your controller clean.
