Core Library

Core Router

The Core class is the Front Controller that parses every incoming URL and automatically resolves the target controller, method, and parameters — with zero configuration required.

Routing Flow

Every HTTP request goes through public/index.php → Core. The URL is parsed into up to three parts: controller / method / params.

1
Parse URL string $_GET['url'] is sanitized, trimmed, and exploded by / into an array.
2
Resolve Controller (url[0]) Checks if app/controllers/{Url0}.php exists. If yes, loads it; otherwise falls back to the default Logins controller.
3
Resolve Method (url[1]) Checks if url[1] is a public method on the instantiated controller. Falls back to index() if not found.
4
Collect Params (url[2+]) Any remaining URL segments are passed as ordered arguments to the resolved method via call_user_func_array().
5
Dispatch The controller method is called with the params array. The controller then loads its model and view.
Default Values
protected $currentController = 'Logins'

The fallback controller loaded when the URL contains no controller segment, or the requested controller file does not exist.

protected $currentMethod = 'index'

The fallback method called when the URL contains no method segment, or the requested method does not exist on the controller.

protected $params = []

Holds all extra URL segments after controller and method. Passed as individual arguments to the called method.

Naming Convention: Controller filenames and class names must match exactly and be ucwords() capitalised. A URL segment products maps to app/controllers/Products.php containing class Products.
getUrl()
public function getUrl() : array|null

Reads the raw $_GET['url'] string, sanitizes it with FILTER_SANITIZE_URL, strips trailing slashes, and returns an array of URL segments.

// Incoming URL: /products/edit/5
// $_GET['url'] = "products/edit/5"

$url = $this->getUrl();
// Returns: ['products', 'edit', '5']

// $url[0] → 'products'  → resolves to Products controller
// $url[1] → 'edit'      → resolves to edit() method
// $url[2] → '5'         → passed as $id parameter
Returns null when $_GET['url'] is not set (e.g., the homepage). In this case, both controller and method fall back to their default values (Logins::index()).
URL Examples

All examples assume URLROOT = http://localhost/mvc-php

URL Controller Method Params
/mvc-php Logins index() —
/mvc-php/users Users index() —
/mvc-php/users/create Users create() —
/mvc-php/users/edit/7 Users edit() ['7']
/mvc-php/users/delete/7 Users delete() ['7']
/mvc-php/products/view/3/gallery Products view() ['3', 'gallery']
Full Example: Controller with URL Param

When the URL is /mvc-php/users/edit/7, Core resolves and calls Users::edit(7).

// app/controllers/Users.php
class Users extends Controller
{
    public function __construct()
    {
        $this->userModel = $this->model('User');
    }

    // Called for: /users/edit/7
    public function edit($id)
    {
        $user = $this->userModel->findById('users', $id);

        $this->view('users/edit', [
            'user' => $user
        ]);
    }
}
Tip: Every controller must extend Controller to gain access to the model() and view() helper methods inherited from the base Controller class.
